BEGINNER ADULT CLASS · 4 × 60 MIN

健身气功·八段锦
四课时教学计划

面向零基础成人班（8—12人）的渐进式教学方案。核心路径：认识身体 → 掌握动作 → 连贯串联 → 独立完整练习。

4课时
60′每节课
8核心动作
1结课能力：独立完整演练

01 · 教学总览

从“会做”到“会练”

🎯 结课目标

  • 掌握起势、八式与收势，顺序不混
  • 独立完成全套，动作路线基本正确
  • 建立基本身型：虚领顶劲、沉肩坠肘、含胸拔背、松腰敛臀、屈膝松胯
  • 呼吸以自然为主，熟练后逐步配合动作
  • 知道常见错误、纠正方法与安全边界

🧭 教学原则

① 分解→完整先局部，后串联
② 下肢→上肢先路线，后细节
③ 松柔优先不追求低马步
④ 呼吸自然初学不憋气

⏱️ 每节课固定节奏

5′集合 / 目标
8–12′热身 / 站桩 / 调息
8–10′复习旧动作
20–30′新授动作

第 1 节｜基础身型 + 起势 + 第一、二式

目标：会站、会呼吸、会前两式
0–5′认识八段锦

源流、功效、练习原则与安全事项。

5–15′热身 + 无极桩 + 调息

颈、肩、腕、腰、髋、膝、踝活动；原地踏步；无极桩2分钟。

15–25′基本身型与手 / 步型

并步、开立、马步、弓步；掌、拳、八字掌；沉肩、松腰、敛臀。

25–40′起势 + 第一式「两手托天理三焦」

掌根上撑、拔伸脊柱、肩沉肘坠；上托吸、下落呼，初学自然呼吸。

40–52′第二式「左右开弓似射雕」

马步稳定、扩胸沉肩、肘与肩平；重点纠正塌腰、膝内扣、耸肩。

52–60′串联 + 放松 + 作业

串联起势—第一式—第二式；每天站桩2分钟，前三个动作各3遍。

第 2 节｜第三、四式

目标：学会「对拉」与「转头不转体」
0–5′提问复习 + 检查身型

快速确认前一课重点。

5–12′热身 + 站桩调息
12–20′复习起势、第一、二式

重点纠正马步与托天。

20–35′第三式「调理脾胃须单举」

上下对拉、身体中正；纠正身体侧歪与手臂过度伸直。

35–50′第四式「五劳七伤往后瞧」

转头不转体，肩髋稳定，颈项放松；避免转体、仰头、耸肩。

50–60′串联 + 放松 + 作业

前四式每天1–2遍；重点体会「对拉」和「转头不转体」。

第 3 节｜第五、六式

目标：控制旋转与前屈幅度
0–5′复习提问

再次强调呼吸自然。

5–12′热身 + 站桩
12–22′复习前四式

纠正第三、四式。

22–37′第五式「摇头摆尾去心火」

马步稳、脊柱侧屈旋转、颈肩放松；慢速小幅，不甩头、不憋气。

37–52′第六式「两手攀足固肾腰」

先屈髋再屈腰，膝可微屈；手到小腿即可，前屈幅度以舒适为度。

52–60′串联 + 放松 + 作业

前六式每天1–2遍；第六式尤其强调缓慢与个体幅度。

第 4 节｜第七、八式 + 收势 + 完整套路

目标：从“会动作”过渡到“独立演练”
0–5′结课目标 + 安全提醒
5–10′热身 + 站桩调息
10–20′复习前六式
20–30′第七式「攒拳怒目增气力」

马步抱拳，冲拳、变掌抓握、回收；强调沉肩、腰腿发力，避免只用手臂。

30–40′第八式「背后七颠百病消」

提踵、上顶、稍停、落踵轻震，共7次；注意平衡与落地力度。

40–45′收势

两掌相叠于丹田，静养片刻，还原；呼吸自然。

45–60′完整跟练 + 抽练 + 评估

完整跟练1遍，重点段落抽练；答疑并布置：每天完整练习1遍，每周至少5天，记录感受。

03 · 结课考核

判断“是否真正学会”
01动作顺序起势 → 八式 → 收势，顺序正确。
02身型中正安舒，沉肩坠肘，松腰敛臀，马步不塌腰。
03动作质量路线清楚，上下相随，柔和缓慢，圆活连贯。
04呼吸不憋气；自然配合，熟练者逐步做到起吸落呼。
05完整演练连续完成全套，无明显停顿或遗忘。
06安全意识知道自身限制，并能主动调整幅度。

04 · 安全与个体调整

安全优先于动作幅度
  • 饭后1小时内、酒后、极度疲劳、发热、急性病期不宜练。
  • 严重高血压、眩晕、颈椎病、腰椎病、膝关节病、孕妇、术后人群，应先咨询医生。
  • 马步高度、前屈幅度、颠足强度均可减小。
  • 出现头晕、胸闷、心慌、关节痛，立即停止并休息。
  • 中老年学员以「微汗、不喘、能说话」为强度参考。
  • 教练口令应缓慢、清晰：镜面示范 → 背面示范 → 个别纠正。
